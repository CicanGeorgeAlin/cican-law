# GLOBAL LAW — ACCURACY STANDARD

## Objective

Accuracy is the project's primary quality metric.

GLOBAL LAW must prefer an incomplete verified record over a complete-looking but uncertain record.

## Five dimensions of accuracy

1. **Authority accuracy** — the source is genuinely authoritative for the claim.
2. **Textual accuracy** — the reproduced or quoted material matches the source.
3. **Temporal accuracy** — the provision is assigned to the correct date/version.
4. **Jurisdictional accuracy** — the rule is assigned to the correct jurisdiction and scope.
5. **Interpretive accuracy** — explanations and relationships do not exceed the evidence.

## Verification rule

A claim may be labelled VERIFIED only when its evidence satisfies the applicable Investigation Gate.

## Two-source rule

For high-impact or ambiguous legal claims, seek corroboration where reasonably possible. Corroboration does not override a primary source; it helps detect transcription, metadata, version and interpretation errors.

## No silent correction

If an apparent inconsistency is discovered:
- preserve the original evidence;
- record the discrepancy;
- investigate;
- correct only through a traceable change;
- retain the previous state.

## Critical-error classes

Immediately block publication or downgrade status when there is:
- wrong jurisdiction;
- wrong provision;
- wrong legal status;
- wrong effective date;
- fabricated citation;
- unsupported court interpretation;
- false legal equivalence;
- authoritative translation incorrectly claimed;
- source identity mismatch.

## Accuracy before coverage

Country count, document count and page count are secondary metrics.

The primary question is:

> **Can a reasonable user trace this statement back to the correct law and understand exactly what remains uncertain?**
