# Security and Integrity Principles

GLOBAL LAW is a legal-information project. Integrity is therefore a core security property.

## Protect the source chain

Never overwrite authoritative source records merely to simplify presentation.

## Immutable evidence

Where practical, preserve retrieval metadata, hashes, timestamps, and source identifiers for important evidence.

## Change history

Legal records must be version-controlled. Corrections should create traceable changes rather than silently rewriting history.

## Separation

Keep:
- source evidence
- structured legal data
- research conclusions
- AI explanations
- website presentation

as distinct layers.

## Human review

Material changes to high-authority legal records should be reviewable before being promoted to citizen-facing current-law results.

## Failure mode

When verification fails, the system should degrade toward transparency:
UNKNOWN or REQUIRES INVESTIGATION is preferable to a confident but unsupported answer.
