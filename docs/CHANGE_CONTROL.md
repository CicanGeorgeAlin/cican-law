# GLOBAL LAW — CHANGE CONTROL

## Principle

Law changes. GLOBAL LAW must change without destroying history.

## Every substantive change records

- object ID;
- previous state;
- new state;
- reason;
- evidence;
- source;
- effective date where applicable;
- discovery date;
- verification date;
- reviewer/review status;
- related objects affected.

## Change classes

- NEW SOURCE
- NEW LAW
- AMENDMENT
- REPEAL
- REPLACEMENT
- COURT INTERPRETATION
- METADATA CORRECTION
- TRANSLATION UPDATE
- RELATIONSHIP UPDATE
- SOURCE URL CHANGE
- VERIFICATION STATUS CHANGE

## Immutable history

Do not overwrite historical legal states merely because a newer version exists.

## Rollback

Every incorrect data change must be reversible through version control and provenance.

## Release rule

A change affecting high-authority legal content must pass the applicable validation and review gates before becoming VERIFIED.
